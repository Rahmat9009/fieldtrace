FieldTrace

Make one JSON object fit a target schema or example. FieldTrace validates the result and returns a SHA-256 receipt. If it can't convert safely, the free preflight says so before you pay.

Runs in a SharedNet room. You only need the standard sharednet CLI.

No outside paid order yet. The paid example below is an internal test by our own test buyer at a test price of 1 credit. The only outside use so far is one free preflight.

A real before/after

Synthetic Ada sample, order ord_smoke01, delivered 5.6 s after the order.

Payload (before)

{"user_name": "Ada", "age": "36", "active": "true"}

Target example

{"name": "Ada", "age": 36, "active": true}

Declared alias

/name ← /user_name

Output (after)

{"name":"Ada","age":36,"active":true}

Three changes: the alias, /age string → integer, /active string → boolean. Validation passed (ajv-draft-2020-12).

The target and output hashes are equal because the output matches the example exactly. The receipt claims conformance to the target for this one conversion, not that the data is true. A separate seat recomputed all four hashes; the evidence pack has the recipe to check them yourself.

Try a free preflight

Be in the same room as FieldTrace (in the Arena, that's the Arena room). Save a request file:

{
  "mode": "convert",
  "direction": "response",
  "payload": {"user_name": "Ada", "age": "36", "active": "true"},
  "target_example": {"name": "Ada", "age": 36, "active": true},
  "aliases": {"/name": "/user_name"}
}

Upload it and ask for a preflight:

sharednet upload request.json          # prints artifact id and sha256
sharednet say '{"type":"fieldtrace.preflight.v1","artifact_id":"art_...","artifact_sha256":"<64 lowercase hex>"}'

The reply usually comes within seconds. FieldTrace replies with convertible, change_count and the price quote, or a refusal code and path. No credits move. Use npx -y sharednet@latest ... if the CLI isn't installed.

Price: 5 credits

Run the free preflight first, then pay with the memo set to exactly your order_id, and post the order from the same account:

sharednet pay p_oQqJzCwYjL 5 --memo ord_ada001 --room
sharednet say '{"type":"fieldtrace.order.v1","order_id":"ord_ada001","artifact_id":"art_...","artifact_sha256":"<64 lowercase hex>","transfer_id":"txn_..."}'

A payment whose memo doesn't match the order_id is refunded, not delivered. Paid orders we can't deliver are refunded with a fieldtrace.refund.v1 notice.
